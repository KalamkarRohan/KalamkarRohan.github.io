Things that broke, and how I fixed them

A running log. Production doesn't care about your free-tier budget.

DOCKER
Compose command not recognizedDocker Compose plugin wasn't installed correctly — CLI kept reporting the subcommand as unknown until the plugin was reinstalled properly.
CI/CD
Self-hosted runner disk fullA GitHub Actions runner filled its disk from repeated build artifacts. Cleared the old runner install and rebuilt cleanup into the workflow.
GIT
Push rejected — fetch firstDiverging remote history blocked a push. Fetched, reconciled the history, and pushed cleanly instead of force-pushing blind.
JENKINS
GitHub webhook returning 403Webhook delivery was being rejected — tracked it to a Jenkins/GitHub authentication mismatch and fixed the credential scope.
TERRAFORM
Provider install failed on a full diskterraform init failed mid-download of the AWS provider because the EC2 instance had run out of storage. Cleaned up and re-ran.
AWS/SSH
Remote SSH connection issues to EC2VS Code Remote-SSH wouldn't connect to a fresh Ubuntu EC2 instance — resolved a key/host config mismatch in the SSH config file.
